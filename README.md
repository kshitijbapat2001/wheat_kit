# wheatkit demo (Hugging Face Space)

To deploy, create a Space and copy `app.py` into it. Add a `requirements.txt` with
`wheatkit[hf]` and `gradio`. Organ segmentation uses the Global Wheat consortium's
`GlobalWheat/GWFSS_Segformer_b1` (CC BY 4.0); credit it on the Space page.
